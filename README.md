# YouTube Money Calculator

Estimate YouTube ad revenue based on daily views and niche RPM.

## Features

- **Niche RPM Selection** — 10 niches from $2 to $12
- **Daily Views Slider** — 100 to 1M with custom input
- **Revenue Cards** — Daily, monthly, yearly earnings
- **Revenue Range** — Low and high estimates
- **RPM Reference Table** — Average RPM by niche
- **FAQ with JSON-LD** — 5 structured data questions
- **Responsive** — Mobile, tablet, desktop
- **Zero dependencies** — Pure vanilla JS

## Getting Started

```bash
npm install && npm run dev
```
